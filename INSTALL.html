FinBot Web — Install & Run Locally

Set up the browser version of your financial bot on this PC in about 10 minutes.

Windows 10 / 11 Python 3.10+ Opens at localhost:5000
Steps
  1. Check Python
  2. Open a terminal in the project folder
  3. Create a virtual environment
  4. Install the packages
  5. Settings (optional)
  6. Start the app
  7. Check that everything works
  8. Starting it next time
  9. Troubleshooting
1

Check Python

Open PowerShell (Start menu → type PowerShell) and run:

PowerShell
py --version
You should see Python 3.10 or newer (3.12 is a good choice).

If py isn't recognised, try python --version instead, and use python wherever this guide says py.

No Python, or it's older than 3.10?
  1. Download the Windows installer from python.org/downloads.
  2. On the first screen, tick “Add python.exe to PATH”, then click Install Now.
  3. Close and reopen PowerShell, then run py --version again.
Prefer to use Anaconda?

That works too. In Anaconda Prompt, create and activate an environment, then skip Step 3:

Anaconda Prompt
conda create -n finbot python=3.12 -y
conda activate finbot
2

Open a terminal in the project folder

The app lives next to your Telegram bot:

C:\Users\villa\Claude Applications\Stock Financial Valuation Analysis\finbot-web

Easiest: open that folder in File Explorer, click the address bar, type powershell and press Enter. A PowerShell window opens already inside the folder.

Or change to it from any PowerShell window:

PowerShell
cd "$env:USERPROFILE\Claude Applications\Stock Financial Valuation Analysis\finbot-web"
Running dir should list app.py, requirements.txt and a static folder.
3

Create a virtual environment

This gives FinBot Web its own private set of packages, so it can't clash with your Telegram bot or anything else on the PC.

PowerShell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
Your prompt now starts with (.venv). Keep this window open for the next steps.
Error: “running scripts is disabled on this system”? Windows blocks the activate script by default. Allow it for your user account once, then run the activate line again:
PowerShell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Or use Command Prompt instead, where the activate command is .venv\Scripts\activate.bat.
4

Install the packages

PowerShell · (.venv) active
python -m pip install --upgrade pip
pip install -r requirements.txt

This takes a minute or two (pandas and numpy are the big ones).

It ends with Successfully installed … and no red errors.
If tradingview-scraper fails to install

It's optional. It only adds next-quarter estimates to reports built from a typed ticker, and the app runs fine without it. Install everything else with:

PowerShell · (.venv) active
pip install flask pandas numpy yfinance requests python-dotenv

gunicorn gets installed too, but it's only used when deploying to Render. It doesn't run on Windows, and you don't need it locally.

5

Settings optional

The defaults work as-is, so you can skip this. To change them, copy the example settings file and edit .env in Notepad:

PowerShell
Copy-Item .env.example .env
notepad .env
SettingWhat it does
SIGNAL_POLL_INTERVAL_SHow often subscribed tickers are checked, in seconds. Default 3600 (hourly).
PORTAdd PORT=5001 if something else is already using port 5000.
TELEGRAM_BOT_TOKENNeeded for ✈ Send to Telegram. Paste the same token your Telegram bot uses (it's in the bot's own .env). See the Telegram box below.
SECRET_KEY, FLASK_ENVOnly matter for deployment. Leave as-is locally.
Setting up “Send to Telegram”
  1. Copy the TELEGRAM_BOT_TOKEN=… line from your Telegram bot's .env into this folder's .env.
  2. In Telegram, open your channel → Administrators → Add Admin → pick your bot and allow Post messages.
  3. Restart the app. In the Analysis tab, open a report, click ✈ Send to Telegram, enter https://t.me/yourchannel and click Send. Channels you've sent to are remembered.

Private invite links (t.me/+…) don't work for bots. For a private channel, use its numeric ID, which starts with -100.

6

Start the app

PowerShell · (.venv) active
python app.py
You'll see Running on http://127.0.0.1:5000.

Now open http://localhost:5000 in your browser.

  • The red “This is a development server” warning is normal for running on your own PC.
  • If Windows Firewall asks about Python, you can click Cancel. Your own browser can still reach the app.
  • Keep the PowerShell window open. Closing it (or pressing Ctrl+C) stops the app, including the hourly signal checks.
7

Check that everything works

Tick these off as you go. Each one needs an internet connection for Yahoo Finance and the charts.

8

Starting it next time

Setup is one-time. After that it's just three commands:

PowerShell
cd "$env:USERPROFILE\Claude Applications\Stock Financial Valuation Analysis\finbot-web"
.\.venv\Scripts\Activate.ps1
python app.py
Want a double-click launcher, like your run_batch.bat?

Save this as run_finbot.bat inside the finbot-web folder. Double-clicking it sets everything up the first time, starts the app, and opens your browser.

run_finbot.bat
@echo off
cd /d "%~dp0"
if not exist ".venv\Scripts\python.exe" (
  echo First run: creating virtual environment and installing packages...
  py -m venv .venv || python -m venv .venv
  ".venv\Scripts\python.exe" -m pip install --upgrade pip
  ".venv\Scripts\python.exe" -m pip install -r requirements.txt
)
rem open the browser a few seconds after the server starts
start "" cmd /c "timeout /t 4 >nul & start http://localhost:5000"
".venv\Scripts\python.exe" app.py
pause
Running alongside the Telegram bot

They're fully independent and can run at the same time, each in its own window. The bot keeps its watchers in notifications.json. The web app keeps subscriptions and the signal feed in finbot-web\signals.json, which is created automatically.

macOS / Linux instead
Terminal
cd path/to/finbot-web
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py

On macOS, port 5000 is often taken by AirPlay Receiver. If so, run PORT=5001 python app.py and open localhost:5001.

Troubleshooting

ProblemFix
py / python is not recognized Python isn't on PATH. Reinstall from python.org with “Add python.exe to PATH” ticked, then open a new PowerShell window.
ModuleNotFoundError: No module named 'flask' The virtual environment isn't active. Run .\.venv\Scripts\Activate.ps1 first; the prompt should show (.venv).
“Address already in use” / port 5000 busy Another program has port 5000. Use a different one: $env:PORT=5001; python app.py, then open localhost:5001. Or set PORT=5001 in .env.
Ticker lookups fail (“No quarterly data found…”, “No price data…”) Check the symbol and your internet connection. If Yahoo changed something, updating usually fixes it: pip install -U yfinance. Uploading a TradingView CSV always works offline.
Reports load but charts are blank Charts use Chart.js from a CDN, so they need internet. A firewall or ad-blocker blocking cdnjs.cloudflare.com can also cause this.
A CSV is rejected with “Missing columns” Export from TradingView with the Mkt cap, Quarterly Revenue, Gross Profit, EBITDA and Free cash flow indicators on the chart, the same as for the bot.
No signals ever appear Signals only fire when a BUY/SELL condition is met on the latest weekly candle, which can take weeks. Checks run only while the app is running.
Send to Telegram says the bot “isn't allowed to post” Add the bot to the channel as an administrator with “Post messages” permission. For groups, the bot just needs to be a member.
Want to start the signal feed fresh Stop the app, delete signals.json in the finbot-web folder, then start it again.
